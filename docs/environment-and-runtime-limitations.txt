6. IMPORTANT PROJECT-SPECIFIC COMPILATION CAUTION

The target project's docs/run-tests.md warns that running
npx hardhat compile can overwrite Poseidon artifacts with placeholder
implementations. The documented Poseidon regeneration step must be
considered before any future compilation attempt.

Poseidon.sol source comments also warn that placeholder bodies are
used and EVM bytecode is injected during deployment using circomlibjs.

Therefore, a future runtime-test setup must preserve the project's
Poseidon artifact-generation requirements. A generic successful
Solidity compile alone would not establish that the cryptographic
test environment is correctly configured.
