ROOT REGISTRATION:
Merkle.sol records roots under rootHistory[treeNumber][merkleRoot].
The newTree() function increments treeNumber during rollover.

ROOT VALIDATION:
Merkle.sol isValidRoot(treeNumber, merkleRoot) checks the tree-specific mapping.
AbstractCoinVault.sol verifyRoot(treeNumber, root) delegates to isValidRoot().

INTERPRETATION:
The Solidity source implements tree-specific root validation.

RUNTIME VERIFICATION — EXP-NF-010:

A Solidity runtime test subsequently exercised the inherited Merkle
implementation after a depth-2 tree rollover.

The test confirmed that a root registered under tree 0 was accepted
under tree 0 and rejected under tree 1. A root registered under tree 1
was accepted under tree 1 and rejected under tree 0.

The test used a local harness and RuntimeMockPoseidon, implemented
using keccak256 modulo the BN254 scalar field. It therefore verifies
tree-specific root-history behaviour in the tested implementation,
not production Poseidon equivalence or the complete production vault
receipt proof-validation path.

REMAINING LIMITATION:

Complete production vault proof validation using a wrong-tree root,
and end-to-end mismatched-tree DvP settlement, remain untested.
