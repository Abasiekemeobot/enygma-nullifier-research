client proof-construction method and real initiator HTTP handler even
when the caller supplies tree number 0 instead of the proof's tree
number, because the circuit verifies the supplied nullifier tree
number separately from the supplied Merkle root and path.

RESULT
PASS. The real client method and real initiator handler accepted the
same valid tree-1 Merkle root/path with both the matching tree number
and the mismatched supplied tree number.

This is direct runtime evidence that the tested client-to-handler path
does not enforce equality between proof.TreeNumber and the caller's
stTreeNumber. The handler verifies the proof using the supplied tree
number for nullifier construction while independently verifying the
provided Merkle root/path.
